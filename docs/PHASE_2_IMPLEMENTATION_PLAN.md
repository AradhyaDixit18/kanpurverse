# Phase 2 implementation plan

8 November 2026. Preserve the existing development branch, $0 budget, 73-test baseline and production. Each milestone ends with scoped regressions, typecheck/lint/build, a logical commit and preview validation where applicable. Production release requires explicit approval after preview gameplay QA.

1. **Audit and vehicle safety (in progress).** Deliver the 22-system audit; geometry-aware exit selection, bounded server validation, blocked-exit recovery, movement gating and disconnect cleanup. Then visible seat-local driver/passenger rigs, camera clearance, replicated transforms and safe mobile exit controls. Gate: all ten types in Rapier plus two actual browser identities; retain previous regression coverage.
2. **Replicated physical interactions.** Add and measure bounded remote-actor proxies; design authoritative collision/state for moving entities before calling multiplayer collisions solved. Include streamed static geometry/infill parity, safe spawn, narrow passages, high-speed contacts and reconciliation. Gate: independent browser sessions and adversarial server tests.
3. **Traffic/navigation.** Shared road graph, persistent lane progress, stopping distance/queues/intersections, crossing state and pedestrian avoidance; simplified distant updates. Gate: no hold/restart teleport, no spawn in buildings, synchronized traffic, measured AI cost. Bicycles/deliveries only after the lane system works.
4. **NPCs/animals and railway integration.** Obstacle-aware walking and ambient state schedules; lightweight land-animal avoidance, birds/perches; authoritative train/crossing sequence and traffic integration. Gate: reproducible navigation/crossing scenarios, stuck recovery and update budgets.
5. **City/character presentation.** Preserve verified geography, fix collider/model bounds; improve facade variety, water/parks/lighting, seated/riding/crouch/point actions. Gate: saved real before/after screenshots, geometry checks and measured tier performance.
6. **Missions/progression/social.** Repair cosmetic equip validation, continuity and atomic valuable persistence before expanding rewards. Play through existing 14; add six distinct missions using real parking, taxi/delivery, exploration, shared activities and railway mechanics across smaller commits. No placeholders, payments, gambling or loot boxes. Gate: completion/failure/replay/reconnect/economy abuse tests.
7. **UI/onboarding/audio.** Redesign around a verified playable loop; working garage/profile/inventory/party flows, concise interactive tutorial and accessibility. Cache approved dialogue; make missing voice explicit, distinguish local Hindi text from authentic Kanpuriya speech. Gate: complete control matrix, three-language audio errors/subtitles, responsive/mobile playthrough.
8. **Performance and release candidate.** Measure frame-time distribution/FPS, draw calls, heap, load, network and AI/physics costs on identified hardware. Optimize only measured bottlenecks; verify Low/Medium/High. Gate: multi-browser and real device QA, preview against matching backend, security triage, explicit release approval.

Each gate can produce a stable partial milestone; no report may label the complete game verified on the strength of a build alone. Current implementation and remaining work are recorded in the topic reports and QA report.
