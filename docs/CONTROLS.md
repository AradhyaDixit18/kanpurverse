# Controls (as implemented in code)

| Action | Key |
|---|---|
| Move | W A S D |
| Sprint | Shift |
| Jump / handbrake | Space |
| Talk / interact / enter vehicle / story action | E |
| Exit vehicle | F (E also works) |
| Horn | H |
| Reset vehicle | R |
| Camera mode (normal/close/far/first person) | C |
| Look back | Q |
| Map | M |
| Missions / story log | J |
| Inventory | I |
| Photo mode | P |
| Help | F1 |
| Pause | Esc |
| Cutscene: next / skip | E or Space or Enter / Esc |
| Emotes | 1–6 |

Touch: an on-screen joystick, drag to look, and buttons. **Not implemented:** an L headlight toggle (headlights follow the time of day), and gamepad support.
